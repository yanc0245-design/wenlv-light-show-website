# 中国大陆与微信公众号上线方案

更新时间：2026-10-29

## 当前状态

公司尚无域名。现有 ChatGPT Sites 链接是需要登录的私有预览，不是面向客户的中国大陆正式网址。代码已改为可直接迁移的静态网站，正式大陆部署、域名注册、备案及微信实机验收尚未完成。

## 推荐路径

公司实名域名 → 国内服务商托管资源 → 企业ICP备案 → DNS解析与HTTPS证书 → 网站发布 → 大陆网络和微信验收 → 配置公众号入口。

优先选择公司可长期管理的域名与账号，不由开发者代持。域名可优先考虑易记的英文或拼音组合加 .com/.cn；可注册性、商标冲突与费用在注册商实时核验，不把候选名字当成已注册域名。

国内托管服务商选阿里云或腾讯云即可；在购买前核验所选资源是否具备备案资格、续费价格及计费上限。若选择大陆 OSS 静态托管，需自定义已备案域名；默认对象存储链接不能直接当成正常官网网址。不要为了先上传网站而盲目购买不支持备案的资源。

## 当前代码适配

- `dist/` 目录可以上传到静态托管、对象存储网站托管或普通 Web 服务器。
- HTML、CSS、脚本、字体和现场图像无境外 CDN 依赖；字体使用系统字体。
- 不需要 ChatGPT 登录、第三方账号登录或付费模型 API。原私有预览的登录限制来自托管入口，不来自网页代码。
- 页面适配手机，移动表单字号为 16px，按钮与文字输入可直接操作。
- 需求信息仅在本机生成，可复制到微信；不强制浏览器下载文件。剪贴板不可用时提供长按复制。
- 保留真实案例；场景策划方向与完工案例明确区分。
- 未配置电话和官方二维码前，不伪装在线收单或自动发送。

## 上线前待办

1. 用户在所选国内注册商完成公司域名注册、实名及账号管理；不在仓库或聊天中提交身份证件、密码或 AppSecret。
2. 在接入服务商核验企业备案材料与托管资源资格，并完成备案。取得真实备案号后在页脚展示并链接到备案查询平台；不填写占位备案号。
3. 配置域名解析、有效 HTTPS 证书、静态站点首页为 `index.html`。只上传 `dist/` 内容，不公开源码目录或配置文件。
4. 根据接入商指引完成适用的后续备案事项。
5. 补齐公开商务电话与官方微信二维码，确认主体名称、素材公开使用权。
6. 确认公众号类型及当前后台的外链权限，选择菜单、阅读原文或其他可用入口。不可假定所有账号都能直接添加外链。
7. 普通展示页面不读取微信用户身份。后续只有需要自定义分享或网页授权时，才按微信官方要求配置对应安全域名与服务端能力；不要在前端放 AppSecret。

## 验收要求

- 使用大陆移动、联通、电信的真实网络抽查，无 VPN 可访问；记录实际测试时间和结果。
- 安卓及 iPhone 微信内打开，测试导航、场景切换、咨询弹窗、复制文字、返回及转发。
- 首屏图片正常加载，证书有效，无登录门槛、强制下载或异常重定向。
- 公众号链接使用最终 HTTPS 域名，并确认公众号后台允许设置该入口。
- 本环境不能代表中国大陆三网或真实微信客户端，不能用云浏览器成功作为国内验收通过的依据。
