# 官网第一版设计与交付范围

日期：2026-10-29

受众：景区、地方文旅集团及夜游项目负责人。目标：通过真实案例了解团队业务，并整理合作需求。

采用用户此前要求的高端文旅风格：深松绿、暖金、米白，中文衬线大标题，现场案例为主视觉；移动优先适配。

方案选择：静态 HTML/CSS/JS，无付费 API，无数据库，无构建依赖。与需要持续运维的 CMS 或服务端相比，适合当前展示与内容量；后续有实际线索管理需求时再加入后台。

页面结构：首页、周祖陵真实案例、四类方案、四步落地流程、公司介绍、项目咨询。实拍素材来自现有周祖陵现场封面。不得将概念图当成真实案例。

功能：站内导航、移动菜单、原生可访问对话框、项目需求单本地文本下载。明确告知未提交，不伪装线上咨询。

待补充：公开商务电话、官方微信二维码、高清原始案例照片及视频、可公开的案例资料。当前保留清晰的联系方式待补充提示。

部署：保留 GitHub 仓库代码；Sites 预览遵循私有默认访问。GitHub Pages 工作流仅在启用 Pages 后运行。代码存储与网站可访问状态分别核验。
